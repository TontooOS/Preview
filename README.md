# Tontoo Preview

Document viewer for TontooOS: empty state with open button, text viewer
with line numbers, Markdown preview plus raw edit mode, manual save
(`Save`, `Ctrl+S`, close dialog). Opens via CLI (`preview /path/to/file`)
or the native file dialog.

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Wiki

See [wiki/MAIN.md](wiki/MAIN.md) for the full documentation.

## Run

```bash
cargo run
cargo run -- /path/to/file.md
```

Bundle ID: `com.tontoo.preview` (see `tontoo.proj`).
